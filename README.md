# Hindi PDF Translator

An internal, self-hosted web app. Upload a Hindi PDF (for example, documents from Beltron) and get an English translation back as Word, side-by-side view, layout-preserving PDF or text. **It uses only free, open-weight models running on our own hardware, with no paid APIs.** Every stage has local fallbacks.

**Status:** planning. See **[PLAN.md](PLAN.md)** for the full design, engine choices, fallback strategy, evaluation plan and roadmap.
